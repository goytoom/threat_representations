# Rerun of threat-vector steering on the 20 held-out scenarios (2026-10-15)

## Why
The hostility-vector steering (`steering/hostile`) was evaluated on the 20 held-out scenarios in
`configs/hostile_config.json` (`eval_questions`), giving n = 20 scenarios x 5 layers = 100 per alpha.
The realistic- and symbolic-threat steering runs (`steering/treatment_realistic`, `steering/treatment_symbolic`)
were evaluated on an older set of 25 scenarios, giving n = 125 per alpha (Tables D46 and D47 in the Nature Communications manuscript; Tables 48 and 49 in arXiv v1).
This rerun evaluates both threat vectors on the same 20 scenarios as the hostility vector.

## What was run
- Model: Mistral-7B-Instruct-v0.3 (float16). Vectors: `persona_vectors/treatment_realistic`, `persona_vectors/treatment_symbolic` (unchanged).
- Script: `test_persona_vector_steering.py` at HEAD (GPT-4o rating prompt on the 1-5 scale), plus a new
  `--fixed_layers` option that skips step 1 and reuses the layers selected in the original runs:
  realistic 13,21,20,9,17 and symbolic 11,13,14,16,18. Steps 2 and 3 ran unchanged (alphas -2, 0, +2; 1 sample per scenario x layer x alpha; temperature 0.7; 100 new tokens).
- Environment: conda `llm_eval` (torch 2.11 cu128, transformers 5.5.4). The `moral-expt` env cannot run on the current GPUs.
- Commands:
  ```
  python test_persona_vector_steering.py --model_path <Mistral-7B-Instruct-v0.3> \
    --vector_dir ./persona_vectors/treatment_realistic/concept_vectors/vectors_npy \
    --eval_cases_path configs/hostile_config.json --output_dir ./steering/treatment_realistic_v2 \
    --use_gpt4_eval --top_k 5 --fixed_layers 13,21,20,9,17
  python test_persona_vector_steering.py --model_path <Mistral-7B-Instruct-v0.3> \
    --vector_dir ./persona_vectors/treatment_symbolic/concept_vectors/vectors_npy \
    --eval_cases_path configs/hostile_config.json --output_dir ./steering/treatment_symbolic_v2 \
    --use_gpt4_eval --top_k 5 --fixed_layers 11,13,14,16,18
  python visualize_steering_summary.py --json_path steering/treatment_realistic_v2/detailed_results/step3_generalization_*.json --output_dir steering_results_summary/treatment_realistic_v2 --shift 0
  python visualize_steering_summary.py --json_path steering/treatment_symbolic_v2/detailed_results/step3_generalization_*.json --output_dir steering_results_summary/treatment_symbolic_v2 --shift 0
  ```
- `visualize_steering_summary.py` is the summary cell of `generate_figures_manually.ipynb` with the hard-coded
  `+1` (0-4 to 1-5 rescaling of the original runs) turned into `--shift`. With `--shift 1` it reproduces the
  three existing `report.json` files exactly. The new runs are rated on 1-5 directly, so `--shift 0`.
